# 🌟 16 Personalities 정밀 성격 유형 검사기

> **16Personalities**의 공식 스타일을 벤치마킹하여 제작된 고품질 반응형 웹 애플리케이션입니다.  
> 5대 성격 지표(Mind, Energy, Nature, Tactics, Identity)와 7단계 리커트 척도를 기반으로 48개 표준 문항을 통해 사용자의 성향을 정밀 분석합니다.

## 🚀 실행 방법 (2가지 중 선택)

### 방법 1. 로컬에서 즉시 실행 (가장 간단)
1. 탐색기에서 `c:\Users\moontaehs\Desktop\mbti` 폴더를 엽니다.
2. `index.html` 파일을 **더블 클릭**하면 크롬, 엣지 등 기본 브라우저에서 즉시 실행됩니다!

## ✨ 핵심 기능 및 특징

1. **16Personalities 시그니처 7점 척도 UI**:
   - 동의(초록) / 비동의(보라) 컬러 대비
   - 가운데는 작고 양 끝으로 갈수록 커지는 정밀 라디오 버튼 애니메이션
2. **5대 척도(총 48문항) 측정**:
   - **정신 (Mind)**: 외향형(E) vs 내향형(I)
   - **에너지 (Energy)**: 직관형(N) vs 현실주의형(S)
   - **본성 (Nature)**: 이성사고형(T) vs 감정형(F)
   - **전술 (Tactics)**: 계획형(J) vs 탐색형(P)
   - **자아 (Identity)**: 자기주장형(-A) vs 신중형(-T)
3. **상세 결과 리포트**:
   - 5대 지표별 백분율(%) 양방향 게이지 바 애니메이션
   - 16가지 성격 유형별 심층 설명, 강점 & 약점, 추천 커리어
   - 성격 궁합(환상의 짝꿍 vs 주의할 관계)
4. **결과 링크 복사 기능**: 친구들에게 내 검사 결과를 공유할 수 있는 링크 복사 지원
